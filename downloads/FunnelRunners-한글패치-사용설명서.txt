Funnel Runners 한글패치
=======================

게임에 한국어가 없어서 게임 파일을 직접 고치는 방식입니다.
내 화면에만 한글로 보이고, 같이 하는 사람 화면은 그대로 영어입니다.
싱글/멀티 모두 됩니다.


설치
----
1. 게임과 스팀을 완전히 종료합니다.
2. 압축을 풉니다. (압축 안에서 바로 실행하면 안 됩니다)
3. "설치.bat" 을 더블클릭합니다.
4. 게임을 못 찾으면 경로를 물어봅니다. 아래 "경로 찾기" 참고.


경로 찾기
---------
스팀 → 라이브러리 → Funnel Runners 우클릭 → 관리 → 로컬 파일 보기
→ StormEscape → Content → Paks 로 들어가서 주소창 경로를 복사.

C드라이브에 깔았다면 보통 여기입니다:
C:\Program Files (x86)\Steam\steamapps\common\Funnel Runners\StormEscape\Content\Paks


제거
----
게임과 스팀을 끄고 "제거.bat" 을 더블클릭하면 원래대로 돌아갑니다.


게임이 업데이트되면
-------------------
패치가 지워지고 영어로 돌아갑니다. 게임은 멀쩡합니다.
새 버전 패치를 받아 다시 설치하세요.

이 패치는 만들어질 당시의 게임 버전에만 맞습니다.
버전이 다르면 "설치.bat" 이 알아서 확인하고 멈추니 게임이 깨질 일은 없습니다.


문제가 생기면
-------------
글자가 네모나 ◆ 로 깨진다
  → 제거.bat 실행 후 설치.bat 다시 실행 (게임을 끄고)

게임이 안 켜진다
  → 제거.bat 실행. 그래도 안 되면 스팀에서
     속성 → 설치된 파일 → 게임 파일 무결성 확인

설치가 실패한다
  → 게임이나 스팀이 켜져 있는 경우가 대부분입니다.
     완전히 끄고, 안 되면 설치.bat 을 관리자 권한으로 실행.


참고
----
· 사람 이름, 상표(APEX 등), 라이선스 고지는 일부러 영어로 뒀습니다.
· 한글 폰트는 나눔고딕(오픈 라이선스)입니다.
  게임 폰트에 한글이 없어서 함께 교체합니다.
