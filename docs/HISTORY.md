# 작업 이력

여러 세션이 이 저장소를 동시에 고칩니다. 작업을 이어받는 세션은 이 파일을 먼저 읽고, 끝나면 맨 아래에 이어서 적습니다. 로컬 PC 경로·계정 정보는 적지 않습니다(공개 저장소).

## 작업 전 규칙

- 시작 전에 `git fetch` 로 origin/main 을 받아 **고칠 게임 파일이 그사이 바뀌지 않았는지** 먼저 확인합니다. 같은 게임을 다른 세션이 먼저 올려 충돌한 일이 있습니다(2026-09-27, 아래 참고).
- 공용 작업 폴더에 다른 세션의 미커밋 변경이 있을 수 있습니다. 올릴 때는 origin/main 기준 별도 worktree 에서 해당 파일만 커밋하는 방식이 안전합니다.
- 측정용 사본(`rock-bal-*.html`, `*-asis.html`, `*.before-*`)은 커밋하지 않습니다.
- 헤드리스 크롬으로 측정할 때 비정상 종료로 남은 탭이 5초마다 저장하며 localStorage 를 오염시킨 적이 있습니다. 측정마다 주소(127.0.0.x)를 따로 쓰고, 끝나면 자기 탭을 닫습니다.

해상도마다 난이도가 달라지는 문제를 없애기 위해 캔버스 게임(참치 타이쿤, 킵 온 마이닝, 쉘다이버, 스페이스 록)을 같은 방식으로 맞췄습니다.

| 원칙 | 내용 |

## 남은 과제 (스페이스 록)

| 문제 | 내용 | 방향 |
|---|---|---|
| 중반 긴장감 약해짐 | 수집 업그레이드가 쌓이면(구역 9 무렵 반경 18유닛) 가만히 있어도 42~64% 수집 | u90 증가량 추가 축소 검토. 진행 속도 재측정 필요 |
| 첫 구역 카드 반복 | 구역 0 은 원작 규칙상 항상 '보통', 굴림 끝에 전설→보통으로 떨어지는 장면이 매 출발 반복 | 구역 0 은 굴림 없이 짧게 표시하거나 속임 칸 제거 |
| 폰 문구 겹침 | 워프 직후 이전 구역의 '할당량 달성 — 스페이스를 누르고 있기' 문구가 카드 아래 겹침, 폰인데 '스페이스' 안내 | 워프 시 이전 안내 문구 정리, 터치 기기 문구 분기 |
| 적극 플레이는 더 쉬워짐 | 원 안 광석이 곧장 날아와 놓치지 않음(82→96%) | 적극 플레이에도 긴장을 원하면 끌어당김 재조정. 낮추면 진행 1.2~1.5배 느려짐(측정) |
| 워프 뒤 효과 잔존 | 화이트홀 남은 시간·특수 탄약이 새 구역까지 이어짐(원작판도 동일) | 필요하면 워프 시 초기화 |
| 사람 플레이 확인 | 광석 수명 2.5초는 봇 기준 값 | 답답하면 수명 4초로 늘리고 반경을 줄여 긴장 유지(재측정 필요) |
