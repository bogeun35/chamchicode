## 1. [A] 타이밍·화면

### 1-1. 공통 규칙

- **과녁**: 음마다 누를 대상(밥 자리, 참돌이, 빵이, 갈매기 자리)에 점선 원을 고정해 둔다.
- **다가오는 링**: 나타난 순간부터 정답 시각까지 **일정 속도로** 줄어든다. 정답 시각에 과녁 크기와 정확히 겹친다.
  - 반지름 `rr = R × (1 + 2k)`, `k = clamp((n.t − s) / lead, 0, 1)`, `lead = n.t − 나타난 시각`
  - 나타날 때 3R, 정답 시각에 R. 정답 전에는 R 보다 작아지지 않는다.
  - 정답 뒤에는 R 에 멈춰 있다가 아슬 창 끝(n.t + CFG.G)에 사라진다. 맞히면 그 즉시 사라진다.
- **정답 순간 번쩍**: n.t 부터 120ms 동안 과녁 테두리가 금색(COL.gold) 굵은 선(lineWidth 10)으로 빛나며 옅어진다. 입력과 관계없이 매번.
- **실전·연습 공통**: 지금의 `pr && n.ring` 조건을 없앤다. 모든 곡, 모든 음에 항상 켠다.
- **속임수(하품·비둘기)에는 과녁·링을 그리지 않는다.** 링이 없으면 누르지 않는다는 신호가 된다.
- **화면 정점 = 정답**: 큐 시각에는 예고 동작(무니 팔, 갈매기 착지, '틱' 글자)만. 정답 시각에 링 겹침 + 번쩍 + 게임별 정점 동작이 온다.
- 허용 어긋남: 표시가 과녁에 닿는 시각 − 정답 시각 **≤ 17ms(1프레임)**.

### 1-4. 화면 시계 = 판정 시계

| 항목 | 규칙 |
|---|---|
| 기준 시계 | 오디오 '들리는 시각' 하나. 그리기·판정 모두 `heardAt()` 기준(지금과 같음) |
| 그리기 | **화면에 실제로 보일 순간의 들리는 시각**으로 그린다. `drawS = songNow() + FRAME_LEAD` (real 모드만, sim 은 0) |
| FRAME_LEAD | rAF 간격의 이동 평균(가중 0.1), 8~25ms 로 제한. 60Hz 에서 약 17ms |
| 판정 | 지금 그대로 `x = at − offS()` |
| 보정값 offS 를 그리기에 넣지 않음 | 보정값은 '들은 박에 누르는 손의 지연'을 잰 값이라, 화면을 보고 누를 때도 같은 손 지연이 붙는다. 그리기에 넣으면 이중 보정이 됨 |
| 출력 지연 | 소리 쪽(`heardAt` 의 getOutputTimestamp·outputLatency)과 입력 쪽(offS)에서만 보정. 그림은 들리는 시각을 따라감 |

```js
// 과녁 + 다가오는 링 + 정답 번쩍 (실전·연습 공통). cT = 링이 나타나는 곡 시각
const VIS = []; let VIS_ON = false;
function drawTarget(x, y, R, n, s, cT, o = {}) {
  const t = o.t != null ? o.t : n.t, j = o.t != null ? n.rj : n.j, at = o.t != null ? n.rat : n.at, lead = t - cT;
  if (s < cT || lead <= 0 || s > t + Math.max(CFG.G, .12)) return;
  const k = clamp((t - s) / lead, 0, 1), rr = R * (1 + 2 * k), aft = s - t, hit = j && j !== 'miss';
  const show = aft <= CFG.G && !(hit && at != null && s >= at);
  if (show) {
    X.save(); X.setLineDash([8, 7]); circ(x, y, R, null, 4); X.strokeStyle = '#fff'; X.lineWidth = 2; X.stroke(); X.restore();   // 과녁
    X.save(); X.globalAlpha = .45 + .55 * (1 - k); circ(x, y, rr, null, 7); X.strokeStyle = o.col || '#fff'; X.lineWidth = 3.5; X.stroke(); X.restore();   // 링
  }
  if (aft >= 0 && aft < .12) { X.save(); X.globalAlpha = 1 - aft / .12; P(); X.arc(x, y, R, 0, Math.PI * 2); X.strokeStyle = o.flash || COL.gold; X.lineWidth = 10; X.stroke(); X.restore(); }   // 번쩍
  if (VIS_ON) VIS.push({ kind: o.t != null ? 'release' : 'ring', id: n.id, x, y, R, rr, show, flash: aft >= 0 && aft < .12, t, cT, zone: n.zone || null });
}
```
