# 스페이스 록 밸런스 측정 봇

rock.html(원작 규칙판)의 진행 속도·긴장감·해상도 동일성을 같은 조건으로 재는 봇입니다. 수치를 바꾼 뒤에는 반드시 기준선과 같은 봇·같은 시드로 나란히 재서 비교합니다.

## 준비

- 저장소 폴더를 정적 서버로 띄웁니다(예: `npx serve -l 8766 .`).
- 원격 디버깅 포트가 열린 크롬이 필요합니다(기본 `http://localhost:9224`, 다르면 `CDP_URL` 환경변수).
- `puppeteer-core` 가 필요합니다(설치 위치가 다르면 `PUPPETEER_CORE` 환경변수에 경로).
- 기준선은 수정 전 rock.html 을 `rock-bal-*.html` 같은 이름으로 복사해 둡니다(이 이름은 커밋하지 않습니다).
- 여러 측정을 동시에 돌릴 때는 주소를 `127.0.0.1`, `127.0.0.2` … 처럼 서로 다르게 줍니다. 주소가 다르면 localStorage 가 분리됩니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| brain.js | 공용: 시드 고정, 페이지 타이머 정지, 봇 두뇌(near 적극 / center 가만히), 한 판 집계 |
| progress3.js | 진행 봇. 새 세이브에서 원정 → 워프 → 귀환 → 상자 → 탐욕 구매 → 플링코(기지 시간 포함) 반복. 구역별 도달 플레이 시간, 시간당 유물, 충돌 종료 비율 |
| tension2.js | 긴장감. 같은 세이브 상태에서 가만히/적극 한 판의 떨어진 광석 수집률 |
| res.js | 해상도 동일성. 1280×720, 2560×1440, 아이폰13 세로에서 near 한 판 파괴 수·광석 가치 |
| cmp.js | 진행 결과를 250분 기준으로 잘라 기준선과 비교 |
| snaps-base-11.json | 긴장감 측정용 세이브 스냅샷(초반·중반) |

## 사용 예

```
node progress3.js --url http://127.0.0.1:8766/rock.html --seeds 11,12,13,21,22,23 --minutes 250 --bot near --out p.json
node tension2.js --url http://127.0.0.1:8766/rock.html --snaps snaps-base-11.json --states early,mid --seeds 12 --cap 120 --out t.json
node res.js --url http://127.0.0.1:8766/rock.html --vp d1280,d2560,m390 --runs 3 --dur 60 --out r.json
```

## 주의

- 봇은 사람보다 훨씬 정확합니다(초당 700 논리 px 완벽 추적). 광석 수명 같은 값은 사람 플레이로 따로 확인합니다.
- 같은 파일·같은 시드라도 판마다 조금씩 달라집니다(6시드 합산 기준 약 ±5%). 3시드 단독으로 판정하지 말고 6시드 이상 합산, 가능하면 두 번 반복합니다.
- 원작판은 250분 안에 구역 20 에 닿지 않습니다. 진행 비교는 구역 10·15 도달 시간과 250분 시점 최고 구역으로 합니다.
