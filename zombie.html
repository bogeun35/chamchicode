❓ 어떻게 하나요?

• 이동: WASD / 방향키 · 모바일은 화면 왼쪽을 끌어서
• 🎯 조준모드: 마우스로 조준 + 누르고 있으면 발사 (피해 +25%) · 모바일은 화면 오른쪽
• 🤖 자동모드: 가까운 좀비를 알아서 쏨 · Tab 으로 전환
• 탄창을 다 쓰면 자동 재장전 (R 로 미리 장전) — 그동안은 근접 무기가 알아서 막아줘요
• 좀비를 잡으면 💰 획득 → 라운드 사이 상점에서 총·아이템 구입
• 라운드마다 팀 특성을 투표로 하나 선택 (전원에게 적용)
• 기지 체력이 0이 되면 실패 — 웨이브를 오래 버텨보세요
